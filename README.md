# Mother Bumper shop website

The public site at motherbumpersticker.com. Plain HTML files, no build step.
Netlify publishes this folder automatically whenever `main` changes.

This repository is public (Netlify's free plan only deploys commits from more than one
contributor on public repos). Keep passwords, keys and private notes out of it.
Sticker pictures in `img/` come from `sticker-design/final/` in the project files.
